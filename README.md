# 音乐封面下载器

一个本地运行、无需安装依赖的音乐封面下载工具。只使用公开歌单分享链接，支持网易云音乐和 QQ 音乐，不提供扫码登录。

> 使用前请阅读 [LEGAL.md](LEGAL.md)。程序启动时会显示强制确认窗口，页面打开后还会显示个人本地合规使用声明。

## 功能特点

- 只接受网易云音乐和 QQ 音乐公开歌单分享链接。
- 不扫码登录，不读取账号 Cookie，不访问私密歌单。
- 支持网易云音乐版权状态识别。
- 支持 QQ 音乐公开歌单封面。
- 按歌曲加入歌单的时间正序编号，最久远加入的歌曲是 `1` 号。
- 支持起止范围，例如 `1-100`。
- 支持指定序号，例如 `1,3,5-8,12`。
- 支持 `640 × 640`、`1080 × 1080` 和原始尺寸封面。
- 支持直接复制完整路径到保存目录输入框。
- 指定目录无法写入时自动改用程序默认 `downloads` 目录，不中断任务。
- 下载完成后显示自愿无偿捐赠窗口；关闭后依次显示“感谢使用”和安全通知。
- 自动识别 JPG、PNG、WebP 等真实图片格式。
- 本地服务只监听 `127.0.0.1`，不向局域网或公网开放。
- 网易云请求强制使用只读 `GET` 端点白名单。

## 平台支持

| 平台 | 分享歌单链接 | 下载封面 | 下载音频 | 当前状态 |
| --- | --- | --- | --- | --- |
| 网易云音乐 | 支持 | 支持 | 不支持 | 已支持 |
| QQ 音乐 | 支持 | 支持 | 不支持 | 已支持 |
| 酷狗、酷我、咪咕等 | 暂不保证 | 暂未实现 | 不支持 | 需要稳定的公开只读接口后再评估 |

本项目不会下载音频、歌词或 VIP 资源，只处理歌曲元数据中可读取的专辑封面。

## 快速开始

### 环境要求

- Node.js 18 或更高版本
- Windows、macOS 或 Linux

不需要安装 npm 第三方依赖。

### Windows

双击：

```text
start.cmd
```

也可以在 PowerShell 中运行：

```powershell
.\start.ps1
```

### macOS 或 Linux

```bash
sh start.sh
```

### 使用 npm

```bash
npm start
```

程序启动后会自动打开：

```text
http://127.0.0.1:38471
```

如果默认端口被占用，程序会自动尝试后续端口。

Windows 首次启动时会先弹出独立警告窗口。只有确认仅用于个人本地、低频、非商业用途后，程序才会继续启动。

如果 Edge 提示 `HTTP ERROR 502`，通常是 VPN、代理软件或 Edge 扩展拦截了 `127.0.0.1`。程序会优先使用无代理的独立浏览器配置打开页面，也可以双击 `open-browser.cmd` 手动打开。

如果 Edge 中的页面样式错乱、弹窗未排版，通常是旧版 CSS 或 JavaScript 被缓存。可以按 `Ctrl+F5` 强制刷新，或使用 `open-browser.cmd` 的无代理独立配置打开。

## 使用方式

### 添加歌单

1. 在网易云音乐或 QQ 音乐中打开歌单。
2. 使用分享功能复制公开歌单链接。
3. 回到本程序，粘贴到“网易云音乐 / QQ 音乐分享链接”输入框。
4. 点击“识别并添加歌单”。

程序只支持公开可访问的歌单，不支持私密歌单。

### 公开歌单

可以把公开歌单链接粘贴到“网易云音乐 / QQ 音乐分享链接”输入框中。

也可以使用 URL 参数直接打开公开歌单：

```text
http://127.0.0.1:38471/?playlist=3778678
```

### 选择下载范围

- 起止范围：下载连续的一段，例如 `1` 到 `100`。
- 指定序号：下载任意位置，例如 `1,3,5-8,12`。

封面默认保存到：

```text
downloads\歌单名称_封面
```

也可以在界面中填写相对目录或绝对目录。

保存目录采用字符输入方式，直接复制并粘贴完整路径即可，例如 `C:\Users\ASUS\Pictures\音乐封面`。

支持直接粘贴带首尾引号的 Windows 路径，程序会自动去除引号。也支持 `%USERPROFILE%\Pictures\音乐封面` 和 `~/Pictures/音乐封面`。

如果下载时出现 `EPERM: operation not permitted`：

- 确认程序是以你的普通用户身份双击 `start.cmd` 启动，而不是运行在受限沙箱中。
- Windows“受控文件夹访问”或安全软件可能阻止程序写入桌面、文档等受保护目录，请允许 Node.js 访问或改用 `D:\下载\音乐封面` 等普通目录。
- 程序会在任务开始前测试目录写入权限；如果目标目录不可写，会自动保存到程序目录的 `downloads` 文件夹，并在日志中显示实际保存位置。

## 编号规则

程序读取歌单接口返回的 `at` 加入时间字段，并按时间从早到晚排序：

- 最久远加入的歌曲是 `1` 号。
- 第二久远加入的歌曲是 `2` 号。
- 没有加入时间字段的歌曲会保留在接口原始顺序之后。

程序同时读取 `noCopyrightRcmd` 和歌曲状态字段，区分：

- 正常歌曲。
- VIP 或付费歌曲。
- 无版权或已下架歌曲。

无版权歌曲通常不能播放或下载音频，但如果歌曲元数据仍然保留封面地址，本项目仍可以下载该封面。

文件命名示例：

```text
0001 - 歌曲名 - 歌手名.jpg
0007 - 歌曲名 - 歌手名.png
```

同一专辑中的不同歌曲会分别生成封面文件，因此可能出现多个文件内容相同的情况。这样能保证文件名编号与歌单序号一致。

## 只读安全说明

项目将“不修改账号内容”作为代码层约束：

- 网易云请求使用固定的只读端点白名单。
- 所有网易云请求强制使用 `GET`。
- 不支持请求体，不存在收藏、新增、删除、编辑歌单的代码路径。
- 不提供扫码登录，不读取账号 Cookie。
- 本地 HTTP 服务只绑定 `127.0.0.1`。

详细说明见 [SECURITY.md](SECURITY.md) 和 [docs/architecture.md](docs/architecture.md)。
