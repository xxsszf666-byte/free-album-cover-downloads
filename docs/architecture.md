# 架构说明

## 运行结构

```text
浏览器界面
    |
    | fetch：仅访问本机 127.0.0.1
    v
Node.js 本地服务
    |
    | GET：网易云 / QQ 音乐 / Apple Music 公开只读接口
    v
网易云音乐 / QQ 音乐 / Apple Music
```

## 核心模块

- `server.js`：本地 HTTP 服务、分享链接解析、歌单读取、下载任务和只读白名单。
- `core.js`：歌单排序、序号解析、歌单链接解析和安全文件名处理。
- `public/`：无构建步骤的 HTML、CSS 和 JavaScript 界面。
- `test/core.test.js`：核心逻辑单元测试。

## 下载流程

1. 识别分享链接属于网易云音乐、QQ 音乐还是 Apple Music。
2. 网易云音乐按 `at` 加入时间从早到晚排序。
3. QQ 音乐和 Apple Music 按公开接口或分享页返回的顺序排列。
4. 解析用户选择的序号。
5. 批量读取选中歌曲的专辑封面 URL。
6. 并发下载图片，并通过文件头识别真实图片格式。
7. 以歌单序号为前缀保存文件。

## 安全边界

本地服务的所有网易云请求都必须经过 `assertReadOnlyNeteaseEndpoint`，非白名单端点会直接抛错。网易云和 QQ 音乐请求均使用公开只读 `GET` 接口，不存在账号写入接口的代码路径。
