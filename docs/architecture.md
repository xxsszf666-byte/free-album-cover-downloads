# 架构说明

## 运行结构

```text
浏览器界面
    |
    | fetch：仅访问本机 127.0.0.1
    v
Node.js 本地服务
    |
    | GET：网易云只读接口
    v
网易云音乐
```

## 核心模块

- `server.js`：本地 HTTP 服务、扫码登录、歌单读取、下载任务和只读白名单。
- `core.js`：歌单排序、序号解析、歌单链接解析和安全文件名处理。
- `public/`：无构建步骤的 HTML、CSS 和 JavaScript 界面。
- `test/core.test.js`：核心逻辑单元测试。

## 下载流程

1. 读取歌单详情中的 `trackIds`。
2. 根据每首歌的 `at` 加入时间倒序排序。
3. 解析用户选择的序号。
4. 批量读取选中歌曲的专辑封面 URL。
5. 并发下载图片，并通过文件头识别真实图片格式。
6. 以歌单序号为前缀保存文件。

## 安全边界

本地服务的所有网易云请求都必须经过 `assertReadOnlyNeteaseEndpoint`，非白名单端点会直接抛错。请求方法固定为 `GET`，不存在写入接口的代码路径。
